## What it is

A free, interactive SQL course for people who have never written a query.

You join the **Meridiano Observatory**, a fictional research institute in Geneva, as a
data analyst. Every lesson is a **mission**: a researcher sends a request — about
inequality, climate, energy, health — and you answer it with real SQL, running in your
browser, on real country data.

- **Real SQL from the very first mission**, on a full database engine (DuckDB) that runs
  inside the page — nothing to install.
- **One new concept per mission**, with an **X-ray** that shows the query happening step
  by step: which rows stay, which go, how groups form.
- **Answers are checked by their result**, not their text: a different way of writing it
  still counts, and when something is off the site tells you *how*.
- A **lab** for free-form queries, a **cheat sheet** with the syntax, and three short
  **games**.
- In Portuguese and English — table names included.

## The data

- **World** — World Bank, *World Development Indicators*, 2000 to 2023, licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The data was downloaded once
  and lives in this repository; the collection date is recorded next to the files.
- **Institute** — the Meridiano Observatory's staff, projects, disbursements, trips and
  publications: **made up**, generated by a script with a fixed seed.

## Tech

Plain HTML, CSS and JavaScript — **no frameworks, no build step**. The only dependency is
[DuckDB-WASM](https://github.com/duckdb/duckdb-wasm), copied into the repository at a
pinned version: nothing comes from a CDN. Progress lives in your browser's
`localStorage` — there is no login and nothing is sent anywhere.

## Running it locally

The project uses ES modules, so browsers refuse to open `index.html` by double-clicking
it. The folder has to be served. Using the Python that ships with macOS:

```bash
python3 servidor.py
```

Then open **http://localhost:8030**.

`servidor.py` is a small, dependency-free local server that tells the browser not to
cache anything, so a code change shows up as soon as the page reloads.

## Layout

```
css/          styles — tema.css holds every color as a CSS variable
js/           logic — screens, SQL engine, editor, X-ray, answer checking
dados/        content — missions, database, games and translations (PT/EN)
fontes/       Source Serif 4 and JetBrains Mono, with their OFL licenses
vendor/       DuckDB-WASM, pinned version
ferramentas/  Python scripts that download and generate the database
```

Content and logic are kept apart on purpose: new missions can be written by editing
`dados/missoes/` alone, without touching the code.
